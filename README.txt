RAVNEET SAGGU — THUMBNAIL DESIGNER PORTFOLIO

FILES
- index.html  : Website structure and content
- style.css   : Dark premium styling and responsive layout
- script.js   : Mobile navigation and portfolio filters

RUN LOCALLY (WINDOWS)
1. Extract the ZIP folder.
2. Open the folder.
3. Double-click index.html.
   It should open in your default browser. Internet is only needed for the Google Fonts.

CUSTOMIZE BEFORE PUBLISHING
1. Replace the six CSS-built sample thumbnail cards in index.html with your real work, or ask for help converting them into image cards.
2. Update the contact email in the two places in index.html if needed. Current address: sagguravneet8@gmail.com
3. Check all copy and only claim services you actually offer.
4. The portfolio cards are illustrative CSS concepts, not real client work. Do not present them as past client projects.

PUBLISHING
You can publish this static site with GitHub Pages, Netlify, or another static host. Test the site on mobile and desktop first.
